# Leaf 0.0.6

A small patch: Leaf no longer skips pages when it opens under a scrolling
pointer, and on Windows it can open comics by double-click.

**Downloads:**

| System | Download |
|---|---|
| Mac, any (macOS 11 or later) | `Leaf-0.0.6-macos-universal.zip` |
| Mac with Apple Silicon / Intel | `Leaf-0.0.6-macos-arm64.zip` / `-macos-x64.zip` |
| Windows, x64 / Arm | `Leaf-0.0.6-windows-x64.zip` / `-windows-arm64.zip` |
| Linux, x86-64 / Arm | `leaf-0.0.6-linux-x64.tar.gz` / `-linux-arm64.tar.gz` |
| The Upscale 4K adapter (unchanged) | `upscale-4k-0.2.0-<system>.zip`, one for each |

On a Mac, the first time, **right-click → Open** (Leaf isn't signed). On
Windows, run Leaf.exe; SmartScreen may ask once (**More info → Run
anyway**).

## What's new

### No more skipped pages at launch

Now and then Leaf opened a few pages past where you left off. The cause:
if you were scrolling in another window when Leaf opened under the
pointer (or when it came to the front), that scrolling went on in Leaf and
turned its pages. Reproduced by scrolling while Leaf opened: it went from
page 1 to pages 10–11 with trackpad-style scrolling and 14–15 with a
mouse wheel.

Now, scrolling that was already going when Leaf opened or came to the
front is ignored until it pauses for a quarter of a second, and fingers
put down on the trackpad afresh count at once. In the same test, 10 runs
out of 10 stayed on page 1, and the next scroll turned exactly one spread.
This holds for scrolling a webtoon too, so your place in the strip stays
put.

### Windows: Open with and double-click

The Windows download has `install.cmd`. Double-click it to:

- put Leaf, with its icon, under **Open with** for comics, EPUBs, PDFs,
  zips and images;
- add "Open in Leaf" to folders' right-click menu;
- open `.cbz`, `.cbr`, `.cb7` and `.cbt` in Leaf by double-click, but only
  where no other app already opens them. An app you chose yourself is
  never replaced.

Only your own account's settings change, and no administrator is needed.
`install.cmd --remove` undoes it. Run it again if you move the folder.
Leaf's window and taskbar button now show Leaf's icon too.

It's a `.cmd` that runs a PowerShell script, because Windows won't run a
downloaded PowerShell script straight from a double-click.

### Checked, and already working

- **Upscaling the next pages ahead of time.** Leaf already asks for the
  next and previous spreads right after the ones on screen, and the
  upscaler makes them too. Full screen with Upscale 4K on an Apple M2,
  turning pages every half second, quarter second and eighth of a second,
  every one of 30 turns found its page ready. Nothing plain is drawn at
  launch either: the first page goes on screen already upscaled.
  `LEAF_TIMING=1` now says, for each turn, whether the page was ready and,
  if not, how long it took.
- **Upscaling in the magnifier.** The magnifier's enlarged picture goes
  through the upscaler like a page does. Upscale 4K handled every size it
  can ask for, up to 6096×8640, in 14–177 ms on the M2.

## Testing

On Windows (x64 and Arm), the release workflow runs `install.cmd` on the
runner's account with another app already set to open `.cbr`. It checks:

- every Open command points at Leaf.exe;
- `.cbz`, `.cb7` and `.cbt` open in Leaf;
- `.cbr` stays with the other app;
- Leaf is in the Open with lists;
- PDFs aren't taken over.

It then starts Leaf with a `.cbz` the way a double-click does, and checks
that `--remove` takes everything out and leaves `.cbr` alone.

## Not tested

- Double-clicking a comic in a real Windows Explorer: the workflow checks
  the registry entries and runs their command, not Explorer itself.
- The skip fix with a real trackpad and mouse: the test sends scroll
  events the way both do, but no one scrolled by hand.

## Compatibility

Everything from 0.0.5 still works: `state.json`, `keys.toml`,
`settings.toml`, every key binding, and adapters (protocol 3, unchanged).
Upscale 4K 0.2.0 and 0.1.0 both work with Leaf 0.0.6.
