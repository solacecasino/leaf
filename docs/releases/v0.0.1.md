# Leaf 0.0.1

The first release of Leaf: a bare comic and manga reader that opens straight
back to the page you were on.

**Download:** `Leaf-0.0.1-macos-universal.zip` (2.9 MB), for Apple Silicon
and Intel Macs on macOS 11 or later. Unzip it and move Leaf.app to
Applications. The first time, **right-click → Open**: Leaf isn't signed
with an Apple developer certificate, so macOS asks once.

## What's new

- **Drag and drop from Finder.** Drop a manga on Leaf's window (a green
  outline shows it'll be taken), on its Dock icon, or on Leaf.app. If Leaf
  isn't running, it starts straight on that book. `.cbz`, `.cbr` and `.cb7`
  files open in Leaf when double-clicked; zips, EPUBs, images and folders
  offer Leaf under **Open With** without changing their default app.
- **A menu bar.** Leaf, File (with Open Recent), View (fit and reading
  direction, with checkmarks), Go, Window and Help, showing your own
  shortcuts from `keys.toml`. New keys: ⌘W closes the book, ⌘↑/⌘↓ go to the
  first and last page, ⌃⌘F is full screen, ⌘, opens the config folder.
- **An icon and a color.** A leaf whose halves open like the pages of a
  book, and Leaf green for the progress line and drop outline.
- **Adapters, the infrastructure.** No adapters ship, but Leaf can now take
  them: separate programs that add commands, or open book formats Leaf can't
  read itself (`opens = ["cbr"]`). Drop an adapter's zip or folder on Leaf to
  install it. An Adapters menu appears once one is installed. Adapters
  crash without taking Leaf down, and their output goes to **Help → Show
  Log**. The protocol is in [docs/adapters.md](../adapters.md).
- **A downloadable app**, with a universal binary.

## Fixed

- Scrolling over Leaf while another app is active (macOS sends scrolling to
  the window under the pointer) no longer turns your page. Scrolling within a
  page in fit-width mode still works.

## Safety

Questions that grant something (install this adapter, allow it to run) have
the safe answer as the default: Return and Escape decline, and saying yes
takes a click. While testing, a dialog that popped up as someone was typing
in another app had been accepted by their Return key.

Installing an adapter through Leaf counts as allowing it. One copied into
the adapters folder by hand is asked about the first time it runs.

## Measured

On an Apple Silicon MacBook, with the release app, a Retina window, and the
demo comic (`cargo run --release --example sample`):

| | |
|---|---|
| Launch to your page on screen | 113–140 ms (355 ms the first time a newly downloaded copy runs, while macOS checks it) |
| Turning to a ready page | one frame |
| Memory with a book open | 65 MB (85 MB with a larger window and an adapter-backed book) |
| Idle CPU | 0% |
| Download / installed | 2.9 MB / 5.1 MB (universal: two architectures) |

## Tested

- Opening books through Finder (Apple Events), both at launch and while
  running, and resuming the last book on launch.
- A test adapter end to end: opening a `.cbr` through it, its commands in
  the Adapters and Go menus, events, `book.get` and `book.goto`, killing it
  mid-book (Leaf kept running and said so), and quitting (no adapter left
  running).
- Installing an adapter zip: Return cancels, clicking Install installs, and
  its command then runs without a second prompt.
- 10 unit tests, including a real adapter process and installs from zips
  and folders.

Not tested by script: dragging onto the window itself. It uses winit's drop
events, as in the prototype, but a real drag can't be scripted here.

## Known limits

- A book read through an adapter needs reopening if that adapter crashes.
  Leaf says so in the title bar.
- Opening a book through an adapter waits for its page list (up to 30 s)
  before the window responds.
- No RAR, 7-Zip or PDF without an adapter, and no text books.
- `keys.toml` changes apply on the next launch.
- Mac only for now; the app isn't notarized.

## Compatibility

Everything from the prototype still works: `state.json`, `keys.toml` and
every key binding. New fields in `state.json` (`recent`, `scale`) are
optional, and old files load as they are.

The first prototype commit called itself 0.1.0. This first release is
0.0.1, and versions count up from here.
