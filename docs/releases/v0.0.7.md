# leaf9000 0.0.7

Leaf is now **leaf9000**, the reader of the 9000 series, next to
[text9000](https://github.com/solacecasino/text9000) (writing),
[splice9000](https://github.com/solacecasino/splice9000) (video),
[wave9000](https://github.com/solacecasino/wave9000) (sound) and
[grace9000](https://github.com/solacecasino/grace9000) (photos). It's the
same reader, renamed, and it now works with its sister apps directly.
Nothing you had stops working.

**Downloads:**

| System | Download |
|---|---|
| Mac, any (macOS 11 or later) | `leaf9000-0.0.7-macos-universal.zip` |
| Mac with Apple Silicon / Intel | `leaf9000-0.0.7-macos-arm64.zip` / `-macos-x64.zip` |
| Windows, x64 / Arm | `leaf9000-0.0.7-windows-x64.zip` / `-windows-arm64.zip` |
| Linux, x86-64 / Arm | `leaf9000-0.0.7-linux-x64.tar.gz` / `-linux-arm64.tar.gz` |
| The Upscale 4K adapter (unchanged) | `upscale-4k-0.2.0-<system>.zip`, one for each |

On a Mac, the first time, **right-click → Open** (leaf9000 isn't signed).
On Windows, run leaf9000.exe; SmartScreen may ask once (**More info → Run
anyway**).

## Working with the 9000 series

- **Open or drop** a text9000 document (`.t9k`, `.folio`), a video, a
  sound file, or a `.splice`, `.wave` or `.grace` project on leaf9000, and
  it opens in the sister app that makes it. If that app isn't installed,
  the title bar says where to get it. Books and pictures, photos included,
  stay in leaf9000: it's the series' reader. An adapter you installed to
  read a kind of file still comes first.
- **The 9000 menu** opens any sister app that's installed, and only those.
  `app grace9000` in `keys.toml` binds one to a key.
- **text9000 sends comics here.** text9000 3.0.1 opens `.cbz`, `.cbr`,
  `.cb7` and `.cbt` files, from a drop, Open or a link in a document, in
  leaf9000.
- **The series look.** A new icon in the series' style: an open book, its
  right-hand page cut on splice9000's slant into leaf9000's colour, page
  gold. The progress line, the drop outline and the magnifier's edge are
  page gold, the background is the series' graphite, and the empty window
  shows the mark.

leaf9000 finds its sisters by itself: on macOS wherever they're installed,
on Linux through their app-menu entries or your `PATH`, and on Windows on
your `PATH` or unzipped next to leaf9000's folder. Otherwise, name their
paths under `[apps]` in `settings.toml`.

## Coming from Leaf

- **Your setup comes along.** On its first start, leaf9000 copies Leaf's
  config folder into its own: where you were in every book, recent books,
  settings, keys, adapters and the adapters you allowed. The title bar says
  so once. Leaf's folder isn't touched, so Leaf 0.0.6 still works if you
  keep it.
- **Your own colours stay.** If you set `background` or `accent` in
  `settings.toml`, they're kept; only the built-in ones are now the
  series'.
- **Adapters work unchanged.** They get the version under both `leaf` and
  `leaf9000`, and the config folder in both `LEAF_CONFIG_DIR` and
  `LEAF9000_CONFIG_DIR`. Upscale 4K 0.1.0 and 0.2.0 both work.
- **`LEAF_TIMING`, `LEAF_CONFIG_DIR` and `LEAF_PDFIUM` still work.**
  `LEAF9000_…` is the new spelling.
- **Windows:** run `install.cmd` from the new folder. It takes out Leaf's
  Open with entry and folder menu item and puts leaf9000's in. The file
  types keep their names from Leaf, so a comic you set to always open with
  Leaf now opens in leaf9000; Windows doesn't let a script change that
  choice, so this was the only way to keep it.
- **Linux:** run `./install.sh` from the new folder. It replaces Leaf's
  app-menu entry, and the comic types Leaf opened by double-click now open
  in leaf9000.

What changes for you:

- The name, the icon and the built-in colours.
- The config folder's name (`leaf9000`) and the log's (`leaf9000.log`).
- The program's name: `leaf9000.app`, `leaf9000.exe`, `leaf9000`.
- The macOS app's identity (`app.leaf9000.reader`). macOS asks once before
  opening it, and `.cbz` files you'd set to "Always Open With" Leaf need
  leaf9000 picked once.
- The Linux window class (`leaf9000`), which matters if you have
  window-manager rules for Leaf.
- The GitHub address. The old one redirects to the new one.

## Measured

On an Apple M2 with a manga open: 82 MB, the same as Leaf 0.0.6 (81–82 MB).
The program is 16 KB larger (2.67 MB for Apple Silicon).

## Testing

- The first start was tried here with a Leaf folder: the book reopened on
  its saved page, the welcome showed once, and Leaf's folder was left as it
  was. A unit test covers copying once, never twice, and a missing folder.
- On this Mac, the 9000 menu listed the three sisters installed here.
  Opening a `.t9k` without text9000 installed said where to get it, and
  opening a sound file started wave9000.
- On Linux and Windows, the release workflow installs leaf9000 where Leaf
  was installed before, and checks Leaf's entries are replaced and the
  comic types follow.

## Not tested

- **On a Mac, hand files to the sisters' newest versions.** On Windows
  and Linux, splice9000, wave9000 and grace9000 already open a file they're
  handed. On a Mac, versions before splice9000 0.0.9, wave9000 0.0.4 and
  grace9000 0.0.3 start empty. Those versions take files from leaf9000,
  text9000, Finder and `open -a`; tried here, a sound went onto a wave9000
  track, a video into splice9000 and a photo into grace9000.
- Finding the sister apps on Windows and Linux has unit tests, but no
  real install was tried.
